# NostrFeed Branding Guide

## Vision
NostrFeed is a **decentralized, community-driven social platform** powered by Nostr protocol and Lightning Network. Our branding reflects:
- **Openness**: Decentralized, user-owned
- **Speed**: Lightning-fast transactions and interactions
- **Community**: Built by and for the community
- **Innovation**: Cutting-edge technology

## Logo Design

### Primary Logo
**Description**: Lightning bolt + Feed/waves combined
- **Shape**: Stylized lightning bolt merged with horizontal waves
- **Style**: Modern, minimalist, geometric
- **Colors**: Primary brand color with secondary accent
- **Variations**: Full logo, icon mark, monochrome

### Logo Specifications

```
Minimum Size: 32px (digital), 1cm (print)
Clear Space: 1/4 of logo width on all sides
Safe Area: Keep logo away from edges by minimum clear space
```

### Logo Colors

```
Primary: #1D88E5 (RGB: 29, 136, 229) - Lightning Blue
Secondary: #FFA500 (RGB: 255, 165, 0) - Energy Orange
Accent: #FFD700 (RGB: 255, 215, 0) - Lightning Gold
Dark: #0A0E27 (RGB: 10, 14, 39) - Deep Navy
White: #FFFFFF - Pure White
```

### Logo Usage Guidelines

✅ **DO**:
- Maintain proper aspect ratio
- Use full color when possible
- Use monochrome on textured backgrounds
- Include adequate clear space
- Use high-resolution versions for digital

❌ **DON'T**:
- Stretch or distort the logo
- Change colors without approval
- Place on low-contrast backgrounds
- Use rotated or skewed versions
- Remove parts of the logo

## Voice & Tone

### Brand Voice
- **Friendly**: Approachable, not corporate
- **Clear**: Simple language, no jargon
- **Empowering**: Emphasize user control
- **Trustworthy**: Transparent about capabilities

### Tone Guidelines

**Technical Content**:
- Educational and clear
- Use short sentences
- Link to detailed documentation

**User Messages**:
- Encouraging, not pushy
- Use "you" language
- Acknowledge user actions

**Error Messages**:
- Helpful and constructive
- Suggest solutions
- Apologize when appropriate

## Visual Style

### Layout Principles

1. **Clean Spacing**: 
   - Use consistent padding/margins (4px, 8px, 12px, 16px, 24px, 32px)
   - White space is your friend

2. **Visual Hierarchy**:
   - Clear primary, secondary, tertiary elements
   - Use size and weight to establish importance

3. **Consistency**:
   - Uniform component styling
   - Predictable interactions
   - Cohesive visual language

### Icons

- **Style**: Outline, modern, minimalist
- **Sizes**: 16px, 20px, 24px, 32px
- **Strokes**: Consistent 1.5px - 2px width
- **Set**: Use Lucide React icons primarily

### Shadows & Depth

```
Elevation 1 (subtle):   0 1px 2px rgba(0,0,0,0.05)
Elevation 2 (card):     0 4px 6px rgba(0,0,0,0.1)
Elevation 3 (hover):    0 10px 15px rgba(0,0,0,0.1)
Elevation 4 (modal):    0 20px 25px rgba(0,0,0,0.15)
```

### Border Radius

```
None:    0px
Tiny:    2px
Small:   4px
Medium:  8px
Large:   12px
XL:      16px
Full:    999px (pills)
```

### Animations

- **Duration**: Fast (150ms), Normal (200ms), Slow (300ms)
- **Easing**: Ease-out for entries, Ease-in for exits
- **Focus**: Only animate interactive elements
- **Performance**: Use transform and opacity for smooth animations

## Accessibility

### Color Contrast
- Minimum WCAG AA: 4.5:1 for text
- Target WCAG AAA: 7:1 for text
- Test all color combinations

### Typography
- Minimum font size: 14px for body text
- Line height: 1.5 or greater
- Letter spacing: -0.02em to 0.05em
- Line length: 50-75 characters optimal

### Interactive Elements
- Minimum touch target: 48x48px
- Clear focus indicators
- Keyboard navigation support
- ARIA labels for screen readers

## DO's and DON'Ts Summary

### ✅ DO
- Maintain consistent visual language
- Use brand colors purposefully
- Keep layouts clean and simple
- Ensure accessibility compliance
- Test on multiple devices
- Follow spacing guidelines
- Use approved fonts
- Keep it professional yet approachable

### ❌ DON'T
- Violate logo safe space
- Change brand colors arbitrarily
- Create cluttered designs
- Ignore accessibility guidelines
- Use unauthorized fonts
- Mix conflicting visual styles
- Overuse animations
- Compromise readability for style
