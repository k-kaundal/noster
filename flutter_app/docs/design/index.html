NostrFeed Design System

The complete design language for the Nostr Operating System — foundations, components, and every screen. Tokens mirror lib/core/theme/ 1:1 so Figma variables and Flutter code never drift. Toggle Light / Dark / OLED above to preview every theme.

Color

Ice-blue identity, hand-specified. Never ColorScheme.fromSeed — M3's seed algorithm skews violet→blue and picks murky surfaces. Light brand is deep ocean #0A66C2 (WCAG AA on white); dark brand is bright ice #4FA3E8 that glows on ocean-charcoal. The full surfaceContainer* ladder is hand-tuned per theme so cards, sheets and the nav pill never look tinted.

Typography

Platform face, tuned ramp. SF Pro on iOS / Roboto on Android — a 2026 app reads "native" with the OS typeface, and the design lives in sizes/weights/tracking. Tight line-heights for feed density; negative tracking on display sizes (the modern Primal/X look). Usage: Theme.of(context).textTheme.* — never raw TextStyle(fontSize:).

Motion & Elevation

Every animation uses AppMotion tokens — zero magic durations in lib/ (sweep complete, ADR-0003). Cheap approaches first: Hero flights, implicit animations, go_router shared-axis transitions. Rive is deferred by ADR.

TokenValueUse
AppMotion.fast150 msMicro-feedback, toggles, fades
AppMotion.normal300 msNav pill slide, page transitions, sheets
AppMotion.curveeaseOutCubic (.2,.8,.2,1)Default — approximates Primal's spring(0.75)
StaggeredListItemper-row delayList entrances (never on feed PostCards — perf rule)
⚡Elevation philosophy: near-flat M3. Cards sit on containerLowest with NO shadow (surfaces do the lifting). Shadows reserved for: floating nav pill (blur 16, y6, 8% alpha), FAB, toasts, and the create button's brand glow.
