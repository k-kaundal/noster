NostrFeed Refined
Refined direction — v2.1

Quiet UI.
Loud content.

The last pass was too loud. Refined goes the other way: small dense type, hairline dividers, one restrained accent, and a real SVG icon system — so the posts people write become the loudest thing on screen. Nothing competes with the content.

13.5px reading type One accent, used sparingly 20px stroke icons, no emoji Hairlines over shadows
01 — Principles

Four rules of the Refined system

Text is the hero

Post body is 13.5px with a 1.5 line-height and tight −0.005em tracking — dense enough to scan, comfortable enough to read 200 posts deep. Headlines exist only where screens need titles; the feed itself is whisper-quiet.

Hairlines, not shadows

Structure comes from 1px #E8EAEF dividers, not elevation. Shadows appear on exactly two things: the FAB and the new-posts pill. Everything else is flat, calm, printable.

One accent, one job

#2F6BFF marks interactive identity: links, the active tab, verified badges, primary buttons. It never decorates. Zap keeps its amber — but muted to #E8860B so it stops shouting.

Icons are a language

One SVG set, 24-viewBox, 1.75px stroke, round caps — drawn for meaning at 16–21px. Emoji survive ONLY in the zap preset grid, where they're cultural shorthand for amounts.

02 — Icon system

The Refined icon set

Consistent stroke weight is what makes an app feel "designed" vs "assembled". Every icon below ships as a Flutter SvgPicture.asset — same 24-viewBox, 1.75 stroke, round joins. Navigation, actions, states, wallet — one family.

09 — The delta

NOVA → Refined: what changed and why

ElementNOVA (too loud)Refined (this doc)
BrandAurora gradient everywhereOne ink + one accent #2F6BFF; gradient retired to logo only
Post textStandard sizes, hero media cards13.5px / 1.5 reading type; media constrained to 16:9 tiles
IconsEmoji + Material mix40-icon SVG set — 24-viewBox, 1.75 stroke, one family
DepthGlass blur, glows, colored shadowsHairlines; shadow only on FAB + new-posts pill
NavFloating glass dock + spring animsSimple top-accent bar — flat, icon-first, tiny labels
ZapNeon orange + glow shadowMuted amber #E8860B, soft tint bg — present, not shouting
VerifiedGradient checkStroke badge-check in accent, 13–15px
WalletNebula gradient + sparklineDark ink statement card, tabular numbers, 2 actions + zap
What survives from NOVA: Explore as a tab (replaces the drawer for discovery), wallet quick-rails for the money features, zap receipts as value cards in chat, and the ⌘K idea (kept as a simple search-first palette, low priority). What dies: gradients as identity, glass, hero media, glow, springs-as-personality. Motion returns to quiet 150–200ms fades.
Implementation cost: lowest of all three directions. It's a new AppTheme pair + an AppIcon widget + PostCard padding/typography tweaks. No layout surgery. Could ship screen-by-screen behind the existing token system in days, not weeks.
NostrFeed Refined · v2.1 · content-first, icons-consistent, quiet by default
Sister docs: index.html (v1.3 reference) · nova.html (the loud dream — now tamed)
