01 — Principles

Five rules that make it feel expensive

Every screen, component and animation in NOVA obeys these. If a design choice violates one, it's wrong.

✦ 01

Aurora is the brand

One signature gradient (blue → violet → pink) used sparingly on moments that matter: verified marks, the create button, zap glow, AI. Everything else stays quiet so the aurora SINGS when it appears.

✦ 02

Glass over chrome

Bars, docks and sheets float as frosted layers over content — the app feels like one continuous surface, not stacked rectangles. Content scrolls UNDER navigation with a 22px saturate blur.

✦ 03

Media is the hero

Photos and video break out of the timeline grid into full-bleed cards. Text posts stay compact; visual posts get cinematic. The feed becomes a gallery, not a spreadsheet.

✦ 04

Physics, not fades

Spring curves (cubic-bezier .34,1.45,.44,1) on every tap, a dock that breathes, buttons that compress and rebound. Motion is the #1 thing users FEEL but can't name.

✦ 05

AI is a companion, not a feature

The aurora-sparkle ✦ appears wherever AI can help — composing, summarizing threads, translating, searching with natural language (⌘K). One assistant, everywhere, never a promo card.

02 — Identity

The aurora system

Ice-blue served us well but reads "enterprise SaaS". NOVA's aurora is ownable — no major social app uses a blue→violet→pink spectrum as identity. It's optimistic, electric, and uniquely Nostr (it literally looks like a zap ⚡).

⚡ Zap stays gold — and now it glows

Zap orange is sacred in Nostr culture and keeps its own ramp (#FFB25B→#FF8A3D) with a signature GLOW on interactive states. The zap button is the only element with a colored shadow — tipping feels physical.

✓ The verified check becomes aurora

NIP-05 verification renders as an aurora gradient check — instantly distinguishable from every other platform's blue check, and impossible to fake with an emoji. Your identity, your spectrum.

03 — Core screens

Home, reborn as a gallery

Stories row with aurora rings (live rings pulse red), a live-activity island for what's happening NOW, text posts kept compact and visual posts elevated to full-bleed hero cards. The floating dock replaces the pill — it breathes with springs and the create button lifts above it.

06 — The delta

Old → NOVA, side by side

Current (v1.3)
  • Ice-blue #0A66C2 — reads "enterprise SaaS", same hue as LinkedIn
  • Bottom-nav pill + Material icons — competent, generic
  • Feed = uniform rows; media constrained to grids
  • Discovery hidden in a 20-item drawer
  • Search is a screen, AI is a destination
  • easeOutCubic 300ms everywhere — smooth but flat
  • Zap button same weight as like/repost
  • Profile = standard cover + stats row
NOVA (v2.0 vision)
  • Aurora spectrum — ownable, electric, uniquely Nostr
  • Floating glass dock, spring physics, ✦ create lifts above
  • Gallery feed — text compact, media full-bleed heroes
  • Explore is a TAB with masonry + trending rings
  • ⌘K palette — search + actions + AI from anywhere
  • Spring curves (.34,1.45,.44,1) — buttons compress & rebound
  • Zap glows with the only colored shadow — value feels physical
  • Profile = personal universe: aurora ring, glass stats, Shop tab
07 — Implementation

From vision to Flutter

NOVA is designed to be buildable with the current architecture — it's a theme + component evolution, not a rewrite. Roughly 80% of the structure (routing, shell, feeds, stores) is untouched.

🎨 Phase 1 — Theme & tokens (1-2 days)

Replace AppTheme schemes with the aurora ramp (keep hand-specified ladder pattern). Add AppGlow token for the zap shadow. Swap easing to spring curves in AppMotion. All WCAG pairs re-pinned in app_theme_test.dart.

🧭 Phase 2 — Dock & shell (2-3 days)

Replace the pill with the floating glass dock: BackdropFilter + spring AnimatedScale on tap. Create button lifts with Transform.translate + gradient border. Add Explore as tab 2 (reorder, Chat keeps badge).

🖼️ Phase 3 — Feed elevation (3-5 days)

PostCard gains a layout: hero|compact switch — media posts (≥1 image/video, no quote) render HeroPostCard full-bleed; text stays compact. Stories row ingests recent media from follows (kind 20/21/22 tail). Live island = dmStoreProvider-style notifier fed by zap/engagement live events.

✦ Phase 4 — ⌘K & AI weave (4-6 days)

Command palette as a route overlay fed by a registry (screens, profiles, actions, AI intents). Long-press dock ✦ opens it. AI intents reuse AiContextService — summarize/translate/draft get token-priced chips inline.

⚠️ What NOVA deliberately does NOT change

PostCard's avatar-left grid (it's correct), chat bubble tails (they read native), zap emoji presets (cultural shorthand), compact profile cover (content-first), the surface-ladder approach (hand-specified forever), and every performance rule in AGENTS.md — memoization, feed rebuild discipline, and the size budget all survive. NOVA is a feeling upgrade, not an architecture churn.
